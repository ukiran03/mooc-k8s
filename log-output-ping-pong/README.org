*** Key Architecture Notes for Future Self

**** 1. GKE Gateway API Constraints (=gke-l7-global-external-managed=)
- *No Method Matching in HTTPRoute:* GKE's Gateway Controller raises error
  =GWCER104= if you use =method: POST= inside =matches=. Method filtering must be
  handled in the application layer (e.g., Go's =http.ServeMux=).
- *Strict Matching Requirements for Rewrites:* Using =ReplacePrefixMatch= inside a
  =URLRewrite= filter strictly requires the corresponding match type to be
  =PathPrefix= (using =Exact= will cause validation errors).

**** 2. Go Router Trailing Slashes
- Gateway API prefix rewrites (rewriting =/= to =/pingpong=) forward requests with
  a trailing slash (=/pingpong/=) to the backend pod.
- To prevent =404 page not found= errors from Go 1.22+ =ServeMux=, register both
  trailing slash variants in your routes:
  #+begin_src go
  mux.HandleFunc("POST /pingpong", app.pingHandler)
  mux.HandleFunc("POST /pingpong/", app.pingHandler)
  #+end_src

**** 3. GCP Load Balancer HTTP POST Requirements
- GCP External Load Balancers return =411 Length Required= if a =POST= request is
  sent without a body or content-length header.
- When testing via =curl=, always pass an empty data payload using =-d ""=.
