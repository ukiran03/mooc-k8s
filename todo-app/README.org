*** 3.9. DBaaS vs DIY
**** Initialization: Works & Costs

|-------------------+----------------------------------------------------------------------+--------------------------------------------------------------------------------------------------|
| Metric            | DBaaS                                                                | DIY(Self-Managed)                                                                                |
|-------------------+----------------------------------------------------------------------+--------------------------------------------------------------------------------------------------|
| Setup Effort      | *Minimal*. Easy provisioning via web-console, CLI etc                  | *High*. Requires configuring OS parameters, installing engine binaries, hardening network security |
| Upfront Cost      | *Low*. Pay-As-You-Go Subscription                                      | *High*. Requires purchasing hardware, data center space                                            |
| Skillset Required | Basic cloud administration and understanding of database connections | Specialized Database Administrators (DBAs) and Systems Engineers                                 |
|-------------------+----------------------------------------------------------------------+--------------------------------------------------------------------------------------------------|

**** Ongoing Maintenance

|---------------------+--------------------------------------------------------------------+-------------------------------------------------------------------------------------------------|
| Feature             | DBaaS                                                              | DIY(Self-Managed)                                                                               |
|---------------------+--------------------------------------------------------------------+-------------------------------------------------------------------------------------------------|
| Patching & Upgrades | *Automated*. The provider rolls out security patches, minor versions | *Manual & Risky*. Our team must track CVEs, test patches in staging, and manually execute updates |
| Scaling             | *Instant*. Scaling vertical or horizontal replicas                   | *Complex*. Requires resizing cloud instances manually                                             |
| Monitoring          | Built-in dashboards                                                | We must deploy, configure, and maintain our own observability stack                             |
|---------------------+--------------------------------------------------------------------+-------------------------------------------------------------------------------------------------|
