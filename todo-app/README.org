**** Important Changes/Notes
#+begin_src text
remove: backend/pv.yaml & frontend/pv.yaml

Using kind: PersistentVolume with local paths (/tmp/kube/...) and hardcoded
node affinities pointing to your old k3d agent (k3d-k3s-default-agent-0).

GKE nodes are managed Google Compute Engine instances; we shouldn't manually
create static local PVs or tie them to ephemeral node hostnames. If that node
scales down or replaces, your data is lost.
---

refactor: {backend,frontend}/pvc.yaml (persistent-volume-claim)

Change storageClassName to GKE's default managed storage class (standard-rwo)
or delete the field to automatically use the cluster default.
---

refactor: ingress.yaml

Update your Ingress manifest to use GKE's standard controller format
---

refactor: database/pg-statefulset.yaml

Explicitly set the GKE storage class here too, so Google Cloud provisions a
persistent disk (pd-balanced or pd-standard)
---

feat(todo-backend): add GET / healthcheck endpoint

Google Compute Engine (GCE) requires a success status code (such as HTTP 200
OK) for its health check probes. This endpoint satisfies those requirements,
transitioning the backend status from UNHEALTHY to HEALTHY and ensuring smooth
traffic flow from the Ingress to application pods.
---
